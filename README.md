# Projekt Fikaguiden (Bootcamp) Nataliia Rusanova FUX25

**Länk till planeringsverktyget**
https://github.com/rusanovasnataly/Fikaguiden

**Projektbeskrivning**

Fikaguiden är en webbplats för personer som vill hitta inspiration till fika. På sidan kan användaren hitta olika fikarecept, filtrera recepten efter kategori, navigera mellan olika delar av sidan, använda sidan med tangentbord, använda sidan på både mobil och desktop.

**Teknik**

Projektet är byggt med: HTML, CSS, JavaScript

## Project Setup

Ladda ner eller klona repot och öppna index.html i en webbläsare.
Projektet kräver inga externa ramverk eller installationer.

## Tillgänglighet

Jag har bland annat: 
Använt semantiska HTML-element som header, nav, main, section och footer.
Använt riktiga button-element för interaktiva funktioner.
Lagt till alt-texter på bilder.
Lagt till synlig fokusmarkering för tangentbordsnavigation.
Lagt till en skip link för att kunna hoppa direkt till huvudinnehållet.
Arbetat med färgkontrast.
Gjort sidan responsiv från 320 pixlar och uppåt.
Sidan innehåller också två interaktiva funktioner som använder JavaScript och DOM-manipulation: receptfiltrering och mobil navigering.
